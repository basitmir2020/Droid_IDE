# Layer Overview

## DroidIDE.App
UI layer (MAUI Android).

## DroidIDE.Core
Domain models, contracts, shared abstractions.

## DroidIDE.Infrastructure
File system, Linux integration, process management.

## DroidIDE.Editor
Monaco + Roslyn integration.

## DroidIDE.Terminal
Terminal execution and session handling.

## DroidIDE.Runtime
dotnet CLI management (build, run, services).

## DroidIDE.ProjectSystem
Solution and project parsing (.sln, .csproj).

## DroidIDE.Git
Git operations using LibGit2Sharp.
